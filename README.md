# Twin Paper Products Website

Responsive React + Vite + TypeScript + Tailwind CSS website for Twin Paper Products.

## Main pages
- Home
- Products catalogue
- Product category pages
- Individual product detail/specification pages
- About
- Private Label
- Contact

## Product categories
- Virgin / Premium Tissues
- Recycled Tissues
- Bamboo Tissues
- Printed Tissues
- Toilet Roll
- HRT Roll

Each product detail page includes specifications and a direct WhatsApp enquiry button.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Upload the generated `dist/` folder to the hosting web root. `public/.htaccess` supports direct React Router URLs on Apache/Plesk.
